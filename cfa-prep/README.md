# CFA Daily — Level I Practice

Mobile-friendly CFA Level I practice quiz in English, with explanations and a Wrong-Answer Book.

## Open the app

After GitHub Pages is enabled, use:

**https://vincidavinci.github.io/vinci/cfa-prep/**

Or open `cfa-prep/index.html` locally in a browser.

## Features

- **Daily drill** — 10 mixed questions
- **Topic practice** — Ethics, Quant, Economics, FRA, Equity, Fixed Income, Derivatives, Alts, Portfolio, Corporate Finance
- **Explanations** after every answer
- **Wrong-Answer Book** — missed questions with your answer + correct answer + explanation
- **Review quiz** — re-test misses; cleared when answered correctly
- **Progress & streak** — stored in your browser (localStorage)
