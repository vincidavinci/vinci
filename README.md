# vinci

## CFA Daily

Mobile CFA Level I practice quiz (English) with explanations and a Wrong-Answer Book.

### Practice on your phone

Open this link in Safari/Chrome, then **Add to Home Screen**:

**https://htmlpreview.github.io/?https://github.com/vincidavinci/vinci/blob/cursor/cfa-prep-quiz-85e6/cfa-prep/index.html**

After this branch is merged to `main`, use:

**https://htmlpreview.github.io/?https://github.com/vincidavinci/vinci/blob/main/cfa-prep/index.html**

Progress (streak, accuracy, Wrong-Answer Book) is saved in your phone browser.

### Local / agent preview

```bash
python3 -m http.server 8765 --directory cfa-prep
```

Then open `http://127.0.0.1:8765/`.

### Features

- Daily 10-question drill, Mixed 15, practice by topic
- Explanation after every answer
- Wrong-Answer Book + review quiz
- 60 English Level I–style questions

Educational practice only — not affiliated with CFA Institute.
